拖入浏览器导出的 .har 文件

自动解析全部接口请求，输入关键字即可定位它出现在哪个接口、哪个字段

  • Chrome / Edge：开发者工具 → Network → 刷新页面 → 右键请求列表 → Save all as HAR with content
  • Firefox：网络 → 右键 → 全部另存为 HAR
  • 检索范围覆盖：URL / Query 参数 / 请求头 / 请求体 / 响应头 / 响应体 / Cookie
  • 响应体为 JSON 时会给出字段路径（如 $.data.list[2].name），非 JSON 文本给出行号
