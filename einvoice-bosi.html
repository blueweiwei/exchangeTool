博思发票加解密

博思电子发票接口参数签名/验签。参数按固定顺序拼接 key=value 字符串，追加 &key=密钥 后 MD5 转大写生成 sign。纯离线，数据不上传服务器。

┌───────────────────────────────────────────────────────────────┐ │ 博思发票 签名/验签 流程 │ ├───────────────────────────────────────────────────────────────┤ │ 签名（加密）： │ │ │ │ ① 原始参数 JSON 做 BASE64 编码 → data │ │ ② 生成随机 UUID 或时间戳 → noise │ │ ③ 按固定顺序拼接（不可调换顺序）： │ │ appid=xx&data=xx&noise=xx&key=私钥&version=1.0 │ │ ④ 对拼接字符串做 MD5 → 结果转大写 → sign │ │ ⑤ 最终参数：{appid, data, noise, version, sign} │ │ │ │ ────────────────────────────────────────── │ │ 验签（解密）： │ │ │ │ ① 提取返回参数中的 {appid, data, noise, version} + 本地 key │ │ ② 按相同规则拼接： │ │ appid=xx&data=xx&noise=xx&key=私钥&version=1.0 │ │ ③ MD5 → 大写，与 sign 字段比较 │ │ ④ 一致 → 验签通过；否则 → 验签失败 │ │ ⑤ 同时 BASE64 解码 data 字段还原原始参数 │ │ │ │ ★ 关键区别：Java 代码拼接时 key 和 version 放在数据之后 │ │ 即 ...&key=私钥&version=1.0（key 在前，version 在后） │ └───────────────────────────────────────────────────────────────┘
JavaScript 核心代码
function generateSign(appId, dataBase64, noise, appKey, version) { // ① 按固定顺序拼接 var raw = 'appid=' + appId + '&data=' + dataBase64 + '&noise=' + noise + '&key=' + appKey + '&version=' + version; // ② MD5 → 大写 return MD5(raw).toUpperCase(); } function encrypt(originalJson, appId, appKey, version) { var data = btoa(unescape(encodeURIComponent(originalJson))); var noise = generateUUID(); var sign = generateSign(appId, data, noise, appKey, version); return { appid: appId, data, noise, version, sign }; } function verify(response, appKey) { var calcSign = generateSign( response.appid, response.data, response.noise, appKey, response.version ); var valid = calcSign === response.sign; var decodedData = atob(response.data); return { valid, calcSign, decodedData }; }
Java 原始实现（对照）
private Map<String, Object> generateHttpParam(Object originalParam) { String appId = ParamUtils.getParameter(ETicket_APPID); String data = JSONObject.toJSONString(originalParam); BASE64Encoder encoder = new BASE64Encoder(); String encodeData = encoder.encode(data.getBytes("UTF-8")); String noise = UUID.randomUUID().toString(); String appKey = ParamUtils.getParameter(ETicket_APPKEY); // 按固定顺序拼接 String reqStr = "appid=" + appId + "&data=" + encodeData + "&noise=" + noise + "&key=" + appKey + "&version=1.0"; // MD5 → 大写 String sign = DigestUtils.md5DigestAsHex(reqStr.getBytes()); sign = sign.toUpperCase(); // 组装返回 httpParam.put("appid", appId); httpParam.put("data", encodeData); httpParam.put("noise", noise); httpParam.put("version", "1.0"); httpParam.put("sign", sign); return httpParam; }
